# Турнир «Бизнес-баттл»

Всего 20 вопросов: Juniors 7, Middles 7, Seniors 6.

Порядок игры: по одному вопросу по кругу — Juniors → Middles → Seniors → снова Juniors. Лиги переключаются сами (кнопка «Дальше» и автопроведение).

Формат строки: `вопрос | ответ (варианты через /) | сложность | баллы | секунд | блок`.
Пустые баллы и секунды берутся из сложности (лёгкий/средний/сложный = 1/2/3 балла, время по сложности).
