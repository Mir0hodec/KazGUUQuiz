# Описание изменений и найденных ошибок

## Версия 1.1.0 — 24 октября 2026

**Проведение игры**
- Только письменные ответы; режим кнопки BUZZ убран из интерфейса и автоигры.
- Три лиги (Juniors, Middles, Seniors) отвечают по кругу, по одному вопросу; лига без команд пропускается.
- Этап «Чтение вопроса»: вопрос на экране, ведущий читает вслух, ответы и таймер — после отсчёта (5–15 с по длине, настраивается); кнопка «Открыть приём сейчас».
- Автоигра закрывает вопрос сразу, если ответили все команды лиги; один перерыв на каждый новый блок.
- Автоматическое награждение: тройка каждой лиги и общий зачёт, проектор листает сам.

**Подключение телефонов**
- Интернет-ссылка через Cloudflare поднимается сама при запуске `start.command`; при смене Wi-Fi — новая ссылка, QR обновляется сам.
- Кнопка «QR на экран», раздел «Регистрация (PIN)».
- Ответ не теряется при обрыве связи: повторная отправка, понятные статусы «Отправляем…», «Ждём связь…».
- Офлайн-коды удалены. При кратковременном обрыве открытая страница повторит отправку ответа после восстановления связи, пока вопрос открыт.
- Очки команды на телефоне скрыты до награждения.

**Проверка ответов**
- Прощает опечатки и слова вокруг ответа («манета», «Продуктовый магазин», «30р», «30 000 тг»); строгий режим для старших лиг.

**Надёжность и безопасность**
- Исправлено: удаление ответившей команды останавливало автоигру; кнопки поверх письменного вопроса; перерыв между блоками при лигах; общий лимит попыток входа через туннель (блокировал всех); лишние процессы cloudflared.
- Задать первый пароль админки можно только на самом ноутбуке.
- Проверено: 97 автотестов, 30 устройств по сети, 1000 клиентов, 400 000 мусорных пакетов, хаос-тест.

**Интерфейс**
- Проектор: экран «Слушаем вопрос», понятные звуки этапов, плашка «включить звук», длинные вопросы и названия помещаются на 16:9 и 4:3.
- Телефон: компактный вход на маленьких экранах, понятные подсказки.


## Версия 1.1.1 — 2 ноября 2026

- «Добавить 10 секунд» на этапе чтения больше не оставляет вопрос без приёма ответов: продлённый таймер чтения сам открывает приём.
- Продление паузы в серверном авто-BUZZ снова продолжает игру: проверка таймера учитывает раунд, а не только письменный вопрос.
- Демо-раздел переведён на письменный формат: отдельный турнир с 30 командами и 12 вопросами; подсказки и подтверждение больше не обещают замену текущих команд.
- Повреждённый `state.json` больше не затирает последнюю хорошую копию `.bak` при запуске.
- Убраны неиспользуемый хук панели и подсказка о несуществующих горячих клавишах; README приведён к версии 1.1.0.
- Добавлена предполётная проверка `npm run preflight` для репетиции и показа.


## Реализовано по ТЗ

- **Блоки, сложность, баллы, время вопроса:** формат вопроса `вопрос | ответ/варианты | сложность | баллы | секунд | блок`; баллы 1/2/3 по сложности или свои; свой таймер у каждого вопроса.
- **Варианты ответа А–З** наравне со свободным текстом; верный вариант не передаётся участникам.
- **Скрытые результаты (§5.2):** участники получают только свои очки.
- **Раскрытие итогов (§5.3):** с последнего места к первому, только тройка, таблица, подиум, нейтральный экран.
- **Блоки:** остановка между блоками с нейтральным сообщением, результаты по блокам, резервная копия в конце каждого блока и игры.
- **Статистика (§4.2, §3.1):** время ответа каждой команды на вопрос, суммарное время, порядок ответов, задержка доставки вопроса на устройство.
- **Равенство баллов:** тай-брейк по меньшей сумме времени верных ответов, иначе совместное место.
- **Возрастные цвета (§6):** junior зелёный, middle жёлтый, senior красный: на проекторе, телефоне и в админке.
- **Архив ответов:** все ответы по вопросам, CSV «Статистика» и «Все ответы», резервные копии `data/backups`.
- **Документы:** инструкции, сеть на четыре роутера, план испытаний, матрица приёмки.
- **Тесты:** полный сценарий 30 команд × 3 блока × 15 вопросов с контрольным подсчётом (`tests/full-game.test.js`).

## Найденные и исправленные ошибки

| Ошибка | Последствие | Исправление |
|---|---|---|
| Телефон показывал место, баллы и лидера | нарушение ТЗ §5.2, интрига до объявления | телефон видит только свои очки; сервер не отправляет таблицу, пока ведущий её не откроет |
| Финал при ничьей выходил за экран | обрезанный нижний список, смещённый подиум | переверстан: помещается при любом числе команд на месте |
| Рейтинг при равных баллах не учитывал время | не соответствовало решению по тай-брейку | добавлен тай-брейк по времени |
| Поля настроек теряли фокус после каждого символа | неудобный ввод | компоненты вынесены из рендера |
| Защита от флуда ограничивала и администратора | быстрые команды администратора «зависали» | вошедший администратор исключён из лимита |
| Автопроведение показывало итоги сразу по окончании списка | раскрытие победителей до действия ведущего | теперь нейтральный экран, итоги по команде ведущего |
| Смена пароля не отключала уже вошедшие сеансы | остаточный доступ | другие сеансы теряют права сразу |
| Цифры таймера могли обрезаться справа (курсив) | нечитаемая цифра | запас справа, без отрицательного интервала |
