# Инструкция администратора (один человек проводит мероприятие)

## До мероприятия

1. Установите Node.js, откройте папку проекта, запустите `start.command` (macOS) или `start.bat` (Windows). При первом запуске откройте `http://localhost:3000/admin` **на ноутбуке** и придумайте пароль.
2. Подготовьте сеть (`СЕТЬ-4-РОУТЕРА.md`), подключите проектор (`/display`, F11).
3. **Создайте турнир** (раздел «Мои турниры» в `/admin`): названия команд и возраст, вопросы, время.
4. Раздайте карточки с QR (раздел «Команды и подключение», карточки для печати). Капитан сканирует QR и попадает сразу в свою команду.
5. Откройте экран проектора в режиме «Старт»: видно, сколько команд подключено.
6. Пробный вопрос и RESET, убедитесь, что 30 из 30 онлайн.

## Редактор вопросов

В разделе «Вопросы» добавляйте задания через поля: текст, ответ, варианты, блок, сложность, баллы и время. Правильный вариант отмечается переключателем. Нажмите «Сохранить вопросы». Во время открытого вопроса и автоматической игры сохранение заблокировано. При уходе с несохранёнными правками появится предупреждение.

## Формат для импорта вопросов

Один вопрос на строку. Столбцы через « | »; всё, кроме текста вопроса, необязательно:

```
вопрос | ответ или варианты | сложность | баллы | секунд | блок
```

Примеры:

```
Столица Франции? | Лондон; Париж*; Рим; Берлин | лёгкий | | 20 | 1
Сколько планет в Солнечной системе? | 8 | средний | | | 1
Самая большая планета Солнечной системы? | Юпитер / юпитер | сложный | | 25 | 2
Вопрос со своими баллами? | да | | 5 | | 3
```

- Варианты разделяются «;», верный помечается «*». Для вопроса с вариантами команды видят кнопки А, Б, В, Г…
- Для текстового ответа можно перечислить несколько верных через «/». Регистр, «ё/е» и знаки препинания не важны.
- Сложность: лёгкий / средний / сложный → 1 / 2 / 3 балла (настраивается в «Турнир»). Свои баллы (4-й столбец) важнее сложности.
- «Секунд» — время именно этого вопроса (например, больше для сложных). Если пусто, берётся общее время.
- «Блок» — номер блока (1–9). Между блоками игра останавливается.
- Ответ и верный вариант видны только вам (карточка «Вопрос N» слева).

## Ход игры (автоматически)

Нажмите «Авто: письменные ответы» (вверху админки) на экране «Проведение игры». Дальше: вопрос → таймер → закрытие → автооценка → пауза → следующий вопрос. Между блоками игра **останавливается**: участники видят нейтральное «Блок N завершён, результаты сохранены», а вы нажимаете «Начать следующий блок». Результаты блока сохраняются автоматически, плюс создаётся копия в `data/backups`.

После последнего вопроса проектор показывает нейтральный экран «Квиз завершён. Подводим итоги»: **ни мест, ни баллов никто не видит.**

## Что видят участники

Только свои очки и «за этот вопрос». Таблица, места и баллы других команд скрыты, пока вы не откроете их сами.

## Объявление результатов

Раздел «Результаты» (раздел «Результаты»):

- «С последнего места» запускает раскрытие, кнопка «Следующее место →» показывает по одному месту от последнего к первому;
- «Только тройка» объявляет 3-е, 2-е, 1-е;
- «Показать таблицу» и «Показать подиум» открывают сразу всё;
- «Скрыть» возвращает нейтральный экран.

При равных баллах выше команда с меньшей суммой времени верных ответов. Если и время одинаково, место совместное.

## Если что-то пошло не так

- Команда пропала: в матрице подключения она серая. Пусть откроет страницу снова, всё восстановится само.
- Ошиблись в оценке: «Отменить оценку» (BUZZ) или кнопка ✓/✗ ещё раз (письменные).
- Нужно остановить автоматику: «Стоп» вверху.
- Закончилось время, а надо добавить: «+10 с / +30 с» рядом с таймером.
- Перезапуск сервера: данные сохраняются; открытый вопрос закрывается, автопроведение выключается.
- Забыли пароль: остановите сервер, удалите поле `"auth"` из `data/state.json`, запустите снова.
- Результаты: «Результаты» → CSV («Итоги», «Статистика», «Все ответы»), копия состояния: `data/backups`.
