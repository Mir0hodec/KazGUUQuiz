# Турнир «Бизнес-квест: Казахстан»

Три лиги по 5 команд (15 команд), только письменные ответы. У каждой лиги своя история из 15 глав.
Лиги отвечают по кругу: Juniors → Middles → Seniors. Свой топ у каждой лиги и общий зачёт.
Время на вопрос, сек: 45
Пауза между вопросами, сек: 10

Juniors — 1–4 классы: «Баурсаки на базаре».
Middles — 5–8 классы: «Кофейня в Астане».
Seniors — 9–11 классы: «Стартап из Алматы».
Каждая глава: ведущий читает её вслух (время на чтение считается само, ~8 с), потом 45 секунд на ответ, 10 секунд пауза.
45 вопросов × ~63 с ≈ 47 минут + регистрация, два перерыва между блоками и награждение — около часа.
Проверка мягкая: опечатки и слова вокруг ответа прощаются. Числа можно писать цифрами, словами, с «тг».

Формат строки: `вопрос | ответ (варианты через /) | сложность | баллы | секунд | блок`.
