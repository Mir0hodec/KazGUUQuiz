# Турнир «Бизнес-ад: часовая порка»

Три лиги, 12 команд (по 4), 40 письменных вопросов. Лиги отвечают по кругу: Juniors → Middles → Seniors → снова Juniors.
У каждой лиги свои вопросы, свой топ и своё награждение, в конце — общий зачёт.
Время на вопрос, сек: 45
Пауза между вопросами, сек: 12
Проверка ответов: строгая

Juniors — 1–5 классы: 14 вопросов по 45 с, проверка мягкая (детские опечатки прощаются).
Middles — 6–9 классы: 13 вопросов по 50 с, проверка строгая.
Seniors — 10–11 классы и взрослые: 13 вопросов по 60 с, проверка строгая.
Примерно 34 минуты на ответы, 8 минут пауз, плюс регистрация, перерыв между блоками и награждение — около часа.
Если ответили все команды лиги, вопрос закрывается сразу.

Формат строки: `вопрос | ответ (варианты через /) | сложность | баллы | секунд | блок`.
Сложность лёгкий/средний/сложный = 1/2/3 балла.
