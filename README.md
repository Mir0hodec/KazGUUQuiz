# QUIZ ARENA

> **Первый раз? Читайте [КАК-ЗАПУСТИТЬ.md](КАК-ЗАПУСТИТЬ.md)** — запуск двойным щелчком по `start.command`, интернет-ссылка для телефонов поднимается сама и переживает смену Wi-Fi.

Локальная система «кнопок» для школьного интеллектуального турнира: 30 команд, телефон капитана, ноутбук ведущего, проектор. Работает в одной Wi-Fi сети, **без интернета** (после установки зависимостей).

Стек: Node.js + Express + Socket.IO, React + Vite + TypeScript, Tailwind CSS, Lucide. Хранение — JSON-файл в `data/`.

## Установка и запуск

Нужен Node.js 18+ (проверено на 26).

```bash
npm install        # один раз, нужен интернет
npm run build      # собрать frontend в dist/
npm start          # сервер на порту 3000 (PORT=3001 npm start — другой порт)
```

**Запуск двойным щелчком:** `start.command` (macOS) или `start.bat` (Windows) — при первом запуске сами поставят зависимости, соберут интерфейс, запустят сервер и откроют админку. Нужен только Node.js.

В консоли будут напечатаны адреса вида `http://192.168.1.100:3000/admin` (IP определяется автоматически) и подсказка про пароль админки.

| Адрес | Для кого |
|---|---|
| `/host` | Старый адрес: переход в единую админку `/admin` |
| `/admin` | единый кабинет: подготовка вопросов и команд, пульт с одной основной кнопкой, таймером и ответами, отдельные результаты лиг, настройки и служебные инструменты |
| `/display` | проектор (F11 — полный экран) |
| `/play` | капитаны (телефоны) |

Разработка: `npm run dev` (Vite на :5173 проксирует на сервер :3000). Тесты: `npm test`.

## Подключение 30 телефонов и проектора

1. Подключите ноутбук и все телефоны к **одной** Wi-Fi сети (роутер должен разрешать связь между клиентами — отключите «AP/Client isolation»; на гостевой сети это обычно включено).
2. На ноутбуке: `npm start`. Откройте `http://localhost:3000/admin`.
3. Вкладка **Команды и счёт**: «Сгенерировать до 30» (или добавьте вручную). У каждой команды свой PIN. Распечатайте/раздайте PIN капитанам.
4. Вкладка **Подключение**: покажите QR-код (ведёт на `/play`). Если у ноутбука несколько адресов — выберите адрес Wi-Fi сети.
5. Капитан сканирует QR, выбирает команду, вводит PIN. Страница запоминает вход и сама переподключается после обрыва. В таблице админки видно статус всех 30 устройств и задержку.
6. Проектор: подключите к ноутбуку (HDMI), откройте `http://localhost:3000/display` на втором экране, F11. Нажмите на страницу один раз, чтобы включить звук. Режим «Старт» показывает QR и число подключившихся команд.
7. Проверьте: откройте кнопки (O) — у всех телефонов кнопка зелёная.

Если в брандмауэре macOS/Windows спросят про входящие подключения Node — разрешите.

## Ход вопроса (письменные ответы)

> В версии 1.1.0 в кабинете ведущего остался только письменный формат. Серверный режим кнопок BUZZ сохранён в коде и тестах, но в интерфейсе отключён.

1. В «Проведении игры» нажмите **«Показать вопрос»** — вопрос появится на проекторе и телефонах.
2. Идёт этап чтения: ведущий читает вслух, ответы ещё не принимаются. Время чтения — 5–15 секунд по длине вопроса или настройка «Время на чтение»; кнопка **«Открыть приём ответов»** открывает приём раньше.
3. После чтения открывается приём: на телефонах поле ввода или варианты А–З, на проекторе «Ответили N / M». Приём закрывается по таймеру или кнопкой **«Завершить приём»**.
4. Ответы проверяются автоматически по ответу из списка; спорные ведущий отмечает ✓/✗ в пульте. Переоценка не дублирует баллы, одинаковые ответы можно отметить разом.
5. **«Дальше»** сохраняет вопрос в архив, увеличивает номер и переключает лигу (Juniors → Middles → Seniors). В авторежиме это происходит само.
6. Экран проектора: Старт (он же QR для входа) / Вопрос / Рейтинг / Финал. Открытие вопроса и сброс возвращают его в авторежим.

## Письменные ответы

### Вопросы с изображениями

В разделе «Вопросы» к любому вопросу можно загрузить PNG, JPEG, WebP или GIF до 8 МБ. Картинка показывается на проекторе, телефонах и в пульте ведущего. В редакторе можно заменить или убрать изображение; изменения вступают в силу после «Сохранить вопросы». На телефоне картинка увеличивается нажатием.

Файлы хранятся в `data/media`, копируются вместе с турнирами и включаются в экспорт данных. В текстовом импорте седьмой необязательный столбец — ссылка вида `/api/media/<имя загруженного файла>`. Внешние ссылки не поддерживаются: сначала загрузите изображение через редактор. При переносе на другой компьютер используйте «Экспорт данных», чтобы сохранить и вопросы, и картинки.

Подготовленный турнир «Финал», его состав и настройки времени описаны в [docs/final/README.md](docs/final/README.md).

Основной режим игры. Текст вопроса берётся из списка «Вопросы» или задаётся вручную. На телефонах появляются вопрос и поле ввода (или варианты А–З) с кнопкой «Отправить ответ»; проектор показывает вопрос и счётчик «Ответили N / M». Каждая команда отвечает один раз: исправить ответ нельзя, сервер отклоняет повторный ответ с другим текстом. **«Завершить приём»** закрывает приём, ведущий отмечает каждый ответ ✓/✗ (переоценка не дублирует баллы; одинаковые ответы можно отметить верными разом). **«Дальше»** возвращает экран к следующему вопросу. Ответы пишутся в журнал и экспортируются в CSV.

## Квиз «300»: блоки, сложность, варианты, итоги

Подробно: папка **`docs/`** (инструкция администратора, сеть на четыре роутера, план испытаний, матрица приёмки, описание изменений).

- **Формат вопроса** (одна строка): `вопрос | ответ или варианты | сложность | баллы | секунд | блок`. Варианты через «;», верный с «*»: `Столица Франции? | Лондон; Париж*; Рим | средний | | 20 | 1`. Сложность лёгкий/средний/сложный = 1/2/3 балла (настраивается), свои баллы и своё время вопроса перекрывают общие.
- **Блоки:** между блоками автоматика останавливается, участники видят «Блок N завершён, результаты сохранены», ведущий нажимает «Начать следующий блок». В конце каждого блока и игры создаётся копия данных в `data/backups`.
- **Скрытые результаты:** участники видят только свои очки. Таблица, места и баллы других команд скрыты, пока ведущий сам их не откроет (раздел «Результаты» в `/admin`).
- **Объявление итогов:** с последнего места к первому, только тройка, таблица, подиум.
- **Равенство баллов:** выше команда с меньшей суммой времени верных ответов, при полном равенстве совместное место. Время зависит от Wi-Fi и телефона, это правило нужно утвердить у заказчика.
- **Возрастные цвета:** junior зелёный, middle жёлтый, senior красный (при создании турнира: `Орлы | junior`, или выбор в таблице команд).
- **Статистика:** время ответа каждой команды, суммарное время, задержка доставки вопроса на устройство; CSV «Статистика» и «Все ответы».

## Полная симуляция турнира

«Служебные инструменты» → «Проверка и демо» → «Полная симуляция турнира» (или `npm run simulate -- --password ПАРОЛЬ`): боты-команды играют весь турнир в реальном времени (думают, ошибаются, теряют связь, отвечают поздно), вы смотрите на `/display` и `/admin`, в конце баллы сверяются с независимым подсчётом. Подробнее: `docs/СИМУЛЯЦИЯ.md`. Симуляция создаёт отдельный турнир и делает его активным (настоящие капитаны отключаются).

## Нагрузочный тест

`npm run load` проверяет сервер на **1000 клиентов** (вход, доставка вопроса, шквал ответов, шквал нажатий, переподключения, длинная игра: `ROUNDS=15 npm run load`). Результаты и ограничения: `docs/НАГРУЗКА.md`. Тест не измеряет Wi-Fi: для 1000 телефонов нужны десятки точек доступа. Лимит команд в турнире — 1000.

## Лиги и сложность

- **Juniors** — младшая лига, зелёный цвет.
- **Middles** — средняя лига, жёлтый цвет.
- **Seniors** — старшая лига, красный цвет.

Цвет и название лиги видны в админке, на телефоне и проекторе. Неиграющие лиги видят «Ответы заблокированы», их ответы и нажатия отклоняются сервером.

В «Настройках» включите «Время по сложности» и задайте секунды: по умолчанию лёгкий — 20, средний — 30, сложный — 45. Там же задаются баллы по сложности (1/2/3). Свои секунды и баллы конкретного вопроса имеют приоритет. В режиме кнопок время уровня относится к ожиданию нажатия, а время устного ответа задаётся отдельно. Вопросы без сложности используют общий таймер.

## Один турнир — три возрастных зачёта

### Автоматическое награждение

В «Результатах» нажмите «Автоматическое награждение» один раз. Проектор последовательно покажет Juniors, Middles, Seniors, общий топ-3, затем общую сетку всех команд. В каждом зачёте сначала появляется заставка на 4 секунды, затем третье, второе и первое места по 8 секунд. Обычная церемония занимает 1 минуту 52 секунды; итоговая таблица остаётся на экране.

Команды, разделившие призовое место, объявляются вместе. Если их больше шести, автоматически показываются дополнительные страницы по 8 секунд. Пустые лиги пропускаются. Призёры фиксируются при запуске церемонии. Изменение счёта, состава команд или возвращение к игре останавливает церемонию; после проверки можно запустить её заново. Старые таймеры при остановке отменяются. Текущий вопрос должен быть закрыт, а его ответы проверены.

При создании включите «Один турнир: младшие, средние и старшие». Для существующего турнира эта настройка доступна на «Главной»; старые вопросы перейдут в набор младших.

- В «Команды и подключение» укажите возраст каждой команды. Все команды находятся в одном турнире и входят по своим постоянным PIN.
- Кнопки «Juniors / Middles / Seniors» выбирают текущую игровую группу. У каждой собственные вопросы и номер вопроса. Перейдите в «Вопросы» и заполните банк выбранного возраста.
- Во время вопроса переключение запрещено. После каждого вопроса «Дальше» и автопроведение сами переключают лигу: Juniors → Middles → Seniors → Juniors. На следующем круге каждая лига продолжает со своего следующего вопроса. Пустые и завершённые банки пропускаются; счёт и прогресс сохраняются. Телефоны других групп показывают ожидание и не могут отправить ответ или нажать кнопку в чужом зачёте.
- В «Результаты» выберите возраст: рейтинг и объявление мест относятся только к нему. CSV итогов включает все три зачёта с местами с первого внутри каждого возраста.
- «Сыграть заново» сбрасывает только выбранную игровую группу. Остальные сохраняют результаты. Создание копии турнира копирует все три банка вопросов и команды, но начинает новую игру с нулевым счётом.

Обычные турниры без возрастного режима продолжают работать как прежде. В режиме кнопок учитываются баллы конкретного вопроса, оценки, их отмена, число верных ответов и время нажатий.

## Кабинет ведущего (`/admin`)

`start.command` / `start.bat` открывают единую админку. Старый адрес `/host` переводит в неё же.

- **Главная:** состояние турнира, подготовка к игре и следующий шаг.
- **Вопросы:** редактор с полями текста, ответа, вариантов, сложности, баллов, времени и блока. Есть поиск, перестановка, удаление и импорт готового списка. Правки сохраняются кнопкой «Сохранить вопросы»; при уходе с несохранёнными правками появляется предупреждение.
- **Команды и подключение:** общий QR, PIN команд, редактирование названий, печатные карточки. Массовое удаление и обнуление спрятаны в дополнительные действия.
- **Проведение игры:** вопрос, таймер и одна основная кнопка следующего действия. Формат, автопроведение, ручной выбор лиги и номера вопроса — в дополнительных действиях. Кнопка «Управлять вручную» возвращает контроль над текущим вопросом. Общий старт заново сбрасывает все зачёты после подтверждения.
- **Результаты:** проверка счёта, объявление мест, CSV и резервные копии.
- **Мои турниры:** создание, копирование, переключение и удаление неактивных турниров.
- **Настройки:** правила, таймеры и пароль. Журнал, демо и симуляция находятся под «Служебные инструменты».

Капитаны используют `/play`, проектор — `/display`. Это отдельные экраны, пароль ведущего им не нужен.

## Турниры

Раздел **Мои турниры**: у каждого турнира свои команды и PIN, счёт, настройки, таймеры, список вопросов и журнал. Можно держать несколько (например «Кубок 8 классов» и «Финал») и переключаться кнопкой «Открыть» в списке турниров. При переключении все капитаны отключаются и входят заново в нужный турнир. Остальные данные не теряются.

- **Создать турнир:** название, число команд или список названий (по одному в строке), баллы, таймеры, вопросы, показ вопроса на проекторе. Сразу открывается.
- **Копия:** берёт команды (с новыми PIN и нулевым счётом), настройки и вопросы существующего турнира.
- **Удалить** можно только неактивный турнир.
- **Демо** создаётся отдельным турниром и не затирает настоящий.

**Вопросы турнира:** по одному в строке, формат `Вопрос | Ответ`. Номер вопроса выбирает строку. Ведущий видит вопрос и ответ в карточке слева (только в админке), «Показать вопрос» подставляет текст сам.

## Автопрограмма (вопрос → пауза → следующий вопрос)

«Проведение игры» → «Формат и дополнительные действия» → «Вести автоматически». Дальше всё идёт само:
1. Открывается письменный вопрос из списка, идёт его таймер (**Настройки → «Письменный ответ, сек»**, например 30 с).
2. Время вышло → приём закрывается, ответы **автоматически проверяются** по ответу из списка (несколько верных вариантов через `/`: `4 / четыре`; регистр, `ё/е` и знаки препинания не важны). Без ответа в списке автооценки нет, ответы остаются в журнале и CSV.
3. **Пауза** (настраивается, «Пауза между вопросами», 0 — без паузы): на проекторе замок «ПАУЗА» и обратный отсчёт, на телефонах жёлтая плашка. Паузу можно продлить кнопкой **«Добавить 10 секунд»**.
4. Открывается следующий вопрос, и так до конца списка (без списка — до остановки). В конце проектор сам показывает финал.

Остановить можно кнопкой **«Управлять вручную»** или ручным сбросом вопроса. Автопрограмма не переживает перезапуск сервера.

## Таймеры

**Настройки → Таймеры** (0 — выключен): время письменного ответа (приём закрывается сам), время на чтение вопроса, пауза между вопросами; для серверного режима BUZZ — время на кнопки и на ответ после нажатия (только отсчёт и сигнал, оценку ставит ведущий). Таймер идёт на сервере, а проектор, телефоны и админка показывают отсчёт по серверному времени, поэтому цифры у всех совпадают. В админке кнопка **«Добавить 10 секунд»** продлевает текущий таймер. Последние 5 секунд — красный мигающий счёт, на проекторе короткие сигналы на 3-2-1 и низкий тон на нуле. После перезапуска сервера активные таймеры не восстанавливаются.

Экспорт CSV (результаты, статистика, ответы, журнал): разделы **«Результаты»** и **«Настройки»**.

## Демо за 2 минуты

«Служебные инструменты» → «Проверка и демо» → «Запустить демо»: создаётся **отдельный** демо-турнир с 30 командами и 12 вопросами, настоящий турнир не затрагивается. Откройте `/display`, в «Проведении игры» нажмите «Показать вопрос» — ответы проверяются сами; в «Результатах» запустите автоматическое награждение. Для игры ботов используйте «Полную симуляцию турнира» в том же разделе.

## Как работает судейство

> Пункты про нажатия и очередь относятся к серверному режиму BUZZ. В интерфейсе 1.1.0 он отключён; письменные ответы оцениваются по ключу или вручную.

- Сервер — единственный источник истины. Идентичность команды берётся из авторизованного сокета (PIN), а не из данных клиента.
- Каждое открытие кнопок получает уникальный `roundId`; нажатия с другим `roundId` отклоняются как `stale`.
- Node.js обрабатывает события в одном потоке: проверка и фиксация победителя синхронны, два победителя невозможны. Повторы одной команды (и повтор того же `nonce`) не меняют результат.
- После первого нажатия приём победителей закрыт; остальные сигналы в течение «окна очереди» (1 с по умолчанию) сохраняются как претенденты, позже — отклоняются (`late`).
- **Честность:** порядок — это порядок обработки на сервере. Он детерминирован, но не компенсирует разницу в Wi-Fi и задержках телефонов; разницу в единицы мс между разными телефонами не следует считать абсолютно точной.
- Защита от флуда: больше 40 пакетов в секунду с одного сокета отбрасываются (запись `security.flood` в журнале), остальных это не затрагивает.
- При запуске последнее успешно прочитанное состояние копируется в `data/state.json.bak`; повреждённый файл сохраняется отдельно как `state.json.corrupt-*` и не затирает копию.
- **Пароль админки.** При первом запуске откройте `/admin` **на ноутбуке ведущего** (адрес `localhost`) и придумайте пароль (от 4 знаков). Задать пароль с другого устройства нельзя. Дальше пароль нужен для входа везде, в том числе на самом ноутбуке. Он хранится только хэшем (scrypt), вход держится 12 часов (токен в браузере), но после перезапуска сервера нужно войти снова; после 5 неверных попыток вход блокируется на 15 с. Сменить пароль можно в «Настройках» (остальные сеансы при этом сбрасываются). Забыли пароль: остановите сервер, удалите из `data/state.json` поле `"auth"` и запустите заново — админка снова предложит задать пароль. Для автоматизации можно задать пароль переменной `ADMIN_PASSWORD`.
- Админ-события доступны только вошедшему админу. Попытки команд выполнить их пишутся в журнал как `security.denied`.
- Все события журналируются с серверным временем (`data/state.log.jsonl`); состояние — в `data/state.json`. Данные переживают перезапуск; открытые кнопки после перезапуска закрываются.

## Структура

```
server/   index.js (запуск), app.js (HTTP + Socket.IO + логика), store.js (JSON-хранилище)
src/      pages/Play.tsx, Admin.tsx, Display.tsx; lib/ (socket, типы, утилиты)
tests/    сервер, лиги, полная игра, проверка ответов, симуляция, туннель и хранилище (vitest)
data/     создаётся при запуске (команды, счёт, журнал)
```

Переменные окружения: `PORT`, `DATA_DIR`, `ADMIN_PASSWORD`.

## Тесты

`npm test` (99 тестов, около 40 секунд): полный сценарий 30 команд × 3 блока × 15 вопросов с контрольным подсчётом (`tests/full-game.test.js`), 30 одновременных нажатий, повтор нажатия, закрытый раунд, запоздавшие сигналы, переподключение и вытеснение сессии, админ-команды со стороны команды, RESET/новый раунд/`stale`, передача права ответа, сохранение после перезапуска, защита CSV, восстановление из резервной копии, повреждённое хранилище.

Перед показом: `npm run preflight` — проверяет сервер, страницы, турнир, счёт и резервные копии. Сценарий показа для инвесторов — [docs/ДЕМО-ДЛЯ-ИНВЕСТОРОВ.md](docs/ДЕМО-ДЛЯ-ИНВЕСТОРОВ.md).

### Архив, резервные копии и допустимые ответы

Новый турнир создаётся с чистым счётом, ответами и историей; вопросы и настройки копируются только при выборе источника. Предыдущие турниры доступны в «Мои турниры», а переключение выполняется вручную. После перезапуска проектор открывает экран ожидания; результаты остаются в архиве и доступны ведущему.

В «Мои турниры» кнопка «Экспорт данных» скачивает JSON со всеми турнирами, настройками, результатами и журналами. «Импорт данных» заменяет текущие данные содержимым файла (до 20 МБ) и рассылает состояние подключённым клиентам. Перед заменой автоматически создаётся резервная копия состояния и журнала. Пароль администратора, его хэш, активные сессии, секрет офлайн-ключей и PIN команд не включаются в экспорт: при импорте сохраняется текущий пароль администратора, а PIN создаются заново. Капитанам нужно войти с новыми PIN.

Данные находятся в `data/state.json`, журнал событий — в `data/state.log.jsonl`, копии состояния и журнала — в `data/backups/` (до 60 комплектов). На вкладке «Журнал» можно скачать журнал активного турнира или всех турниров в JSONL. Резервные копии в папке `data` содержат служебные данные и должны храниться в защищённом месте.

В редакторе письменного вопроса можно добавить допустимые формулировки к основному ответу, например «лого», «logo» и «logotype» к «логотип». Регистр и типичные опечатки учитываются; строгий режим допускает меньше опечаток. Прежний формат с вариантами через `/` продолжает работать.

Пульт ведущего открывается сразу после входа. Основная кнопка запускает автоматическую игру, ручное проведение доступно рядом. «Взять управление» останавливает автопроведение; «Продолжить автоматически» возвращает его к текущему вопросу без сброса ответов. Если ответ нельзя оценить автоматически, игра ждёт ручной проверки: оцените ответы и нажмите «Продолжить игру». Вспомогательные разделы находятся в меню «Ещё».

Офлайн-коды отключены. При кратковременном обрыве связи открытая страница капитана повторит отправку ответа после переподключения, пока этот вопрос ещё открыт. Если приём уже закрыт, обратитесь к ведущему.

После автоматического награждения, ручного раскрытия последнего места или показа пьедестала проектор переходит к общей таблице всех команд и их баллов. При количестве более 30 команд страницы таблицы переключаются автоматически.
